I want to redesign my existing web app, “BoulderMove – Smart Trip Dashboard,” into a much more modern, polished, production-quality transportation/trip-planning website.

The current application already has:
- Origin and destination inputs
- Driving/transit route selection
- A map
- Route options
- Weather information
- Alternative routes
- Transit stops
- Light/dark mode

Do NOT remove the existing core functionality. Instead, completely modernize the UI/UX, improve the information hierarchy, and restructure how trip planning and transit information are displayed.

DESIGN DIRECTION

The website should feel like a modern transportation/navigation product inspired by the clean UX of Google Maps, Apple Maps, Uber, Transit, Linear, and modern SaaS dashboards.

It should NOT look like a basic Bootstrap dashboard.

Avoid:
- Huge empty cards
- Excessive borders
- Too many separate boxes
- Emoji-based branding
- Heavy gradients
- Excessive glassmorphism
- Oversized buttons
- Cluttered layouts

Use a clean, minimal, premium design.

Use:
- Background: #F6F7F9 or a similar very light neutral
- White primary surfaces
- Deep Boulder-inspired teal/green as the main accent
- Very subtle borders
- Soft shadows
- 14–18px border radius
- Generous whitespace
- Modern typography such as Inter, Geist, or Manrope
- Clear visual hierarchy
- Smooth but subtle hover/transition animations
